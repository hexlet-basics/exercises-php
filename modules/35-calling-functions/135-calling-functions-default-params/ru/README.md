Некоторые функции в PHP имеют **необязательные параметры**. Это значит, что для них заранее задано значение по умолчанию, и при вызове можно этот параметр не указывать.

![Автосервис](./assets/default-parameters.png)

Рассмотрим встроенную функцию `round()`, которая округляет число:

```php
<?php

$result = round(10.25, 0); // 10
```

Мы передали в нее два значения:

- Число, которое нужно округлить.
- Точность округления, `0` означает, что округление будет до целого числа.

Так как чаще всего нужно именно округление до целого, создатели функции `round()` сделали второй параметр необязательным и задали ему значение по умолчанию `0`. Поэтому результат будет тем же, даже если второй параметр не указывать:

```php
<?php

$result = round(10.25); // 10
```

Если нужна другая точность, то ее можно указать явно:

```php
<?php

// округление до одного знака после запятой
$result = round(10.25, 1); // 10.3
```

```text
round(10.25, 1)  →  аргументы: 10.25, 1    →  10.3
round(10.25)     →  аргументы: 10.25, (0)  →  10
                                       └── значение по умолчанию
```

В сигнатуре `round()` обязательный параметр `$num` стоит перед необязательным `$precision`. У другой функции количество параметров и их значения по умолчанию могут отличаться.

## Как читать документацию функции

Документация описывает, какие данные принимает функция и какой результат возвращает. Страница функции в [руководстве PHP](https://www.php.net/manual/ru/) делится на разделы. Раздел «Описание» содержит сигнатуру, то есть имя функции, параметры и их порядок. Раздел «Список параметров» объясняет назначение каждого параметра, а раздел «Возвращаемые значения» описывает результат. Чтобы составить вызов, нужны все три раздела.

Разберём [справку о `round()`](https://www.php.net/manual/ru/function.round.php). Если её немного упростить, сигнатура выглядит так.

```php
round(int|float $num, int $precision = 0): float
```

Имена `$num` и `$precision` обозначают параметры. При вызове на их места подставляются конкретные значения, например `round(10.25, 1)`. Перед каждым именем указан тип значения, которое ожидает функция.

В таблице сопоставлены части сигнатуры и аргументы этого вызова.

| Часть сигнатуры | Что она означает | В вызове `round(10.25, 1)` |
| --- | --- | --- |
| `round` | Имя функции | Вызываем `round()` |
| `int\|float $num` | Обязательный параметр, целое или дробное число для округления | Передаём `10.25` |
| `int $precision = 0` | Необязательный параметр, целое число со значением по умолчанию `0` | Передаём `1` вместо значения по умолчанию |
| `: float` | Тип результата | Получаем дробное число |

Знак `=` в `$precision = 0` сообщает о значении по умолчанию. Из этой записи видно, что второй аргумент можно пропустить. Как именно функция использует `0`, объясняет раздел «Список параметров». У `round()` точность `0` означает округление до целого числа.

Раздел «Возвращаемые значения» уточняет результат. В справке о `round()` сказано, что функция возвращает число с плавающей точкой (`float`), округлённое до указанной точности. Поэтому даже при округлении до целого результат остаётся дробным числом.

В полной сигнатуре из документации есть ещё один необязательный параметр `$mode`, который управляет режимом округления. Он нужен редко, поэтому мы его пока не рассматриваем.

Проверим оба случая в интерактивной оболочке PHP. Она запускается командой `php -a`. Строка `php >` обозначает приглашение оболочки. Оболочка сама результат не печатает, поэтому выведем его функцией `var_dump()`, которая показывает тип и значение.

```console
php > var_dump(round(10.25, 1));
float(10.3)
php > var_dump(round(10.25));
float(10)
```

Здесь первый вызов передаёт точность `1` и получает число `10.3`. Второй оставляет `$precision` по умолчанию и получает `10` с типом `float`, как и обещает раздел «Возвращаемые значения». Так мы сопоставляем сигнатуру, объяснение в документации и результат выполнения.

## Обозначения в справке

В сигнатуре встречаются служебные обозначения. Они помогают прочитать сигнатуру и при вызове в функцию не передаются.

| Запись в справке | Как её читать |
| --- | --- |
| `int $precision = 0` | У `$precision` есть значение по умолчанию, аргумент можно пропустить |
| `int\|float $num` | Параметр принимает значение любого из перечисленных типов |
| `?string $decimal_separator` | Знак `?` разрешает передать вместо строки значение `null` |
| `round(float $val [, int $precision = 0])` | Так необязательные аргументы обозначали в старых версиях руководства. Квадратные скобки не входят в вызов |

Например, запись `int|float $num` описывает один параметр. Вызов `round(-5.5)` передаёт ему число `-5.5` и возвращает число `-6`. Ни тип, ни имя `$num`, ни знак `|` в такой вызов не копируются.

Если браузер переводит страницу, имена функций, параметров и символы в сигнатуре нужно сверять с оригиналом. На русской версии руководства описания переведены, а сигнатура остаётся на английском. В коде используются исходные имена из документации.

## Работа с незнакомой функцией

Чтение справки начинается с задачи. Например, для округления цены до одного знака после запятой в сигнатуре `round()` находим число и точность, в списке параметров проверяем смысл точности, затем пробуем вызов `round(10.25, 1)`. Если результат соответствует описанию, этот вызов можно использовать в программе.

У другой функции будут свои параметры и правила. По её сигнатуре мы определяем, какие аргументы передать, по описанию узнаём результат и ограничения, а на небольшом примере проверяем своё понимание.
